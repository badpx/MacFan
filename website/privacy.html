MenuGauge

Privacy policy

Effective October 27, 2026

MenuGauge is a menu-bar monitor for macOS. This policy covers both editions: the direct download from this website, and the Mac App Store edition. Both are named MenuGauge.

What it reads

MenuGauge reads system statistics on your Mac and shows them in the menu bar and in its panel. That includes CPU and GPU use, memory, disk space, and network speed. Network speed is calculated on the Mac from the byte counters of local network interfaces. Those counters are not sent anywhere.

The direct edition also reads fan speed and CPU temperature on the Mac. The App Store edition does not offer a fan reading. Its temperature figure is the system thermal state. The menu-bar gauge uses that same thermal state.

What it does not do

MenuGauge does not collect or transmit data. There is no account, no advertising, no analytics, and no third-party SDKs. The app does not contact this website. It does not download release.json, and it does not check for updates.

Settings

The menu-bar readings you turn on are stored only on this Mac, in the app’s UserDefaults. Launch at login uses the system login item. Those settings are not sent anywhere.

The two editions

The direct edition is not sandboxed. Its code still does not open a network connection. The Mac App Store edition is sandboxed. Its entitlements do not include a network client, so the system does not allow that edition to open network connections.

This website

This site is static. It does not run analytics. Choosing another language opens another page here. release.json is used only while the site is built, to find the current download. The app never requests it. Pages other than Simplified Chinese show this English policy.

Contact

Questions and requests go to GitHub issues.

MenuGauge

隐私政策

生效日期：2026年10月27日

MenuGauge 是 macOS 菜单栏监控工具。本政策适用于两个版本：从本网站下载的直接分发版，以及 Mac App Store 版。两者的名称都是 MenuGauge。

它读取什么

MenuGauge 在你的 Mac 上读取系统统计，并显示在菜单栏和面板里。其中包括 CPU 与 GPU 占用、内存、磁盘空间和网速。网速是在本机根据本地网络接口的字节计数计算的，这些计数不会被发送出去。

直接分发版还会在本机读取风扇转速和 CPU 温度。App Store 版不提供风扇项，温度显示的是系统热状态。菜单栏里的仪表使用同一个热状态。

它不做什么

MenuGauge 不收集、也不传输数据。没有账户，没有广告，没有分析统计，也没有第三方 SDK。应用不会联系本网站，不会下载 release.json，也不会检查更新。

设置

你在菜单栏开启的指标只保存在这台 Mac 上，写在应用自己的 UserDefaults 里。开机自启动使用系统登录项。这些设置不会被发送到别处。

两个版本

直接分发版没有沙盒。它的代码仍然不会发起网络连接。Mac App Store 版在沙盒中运行，其授权不包含网络客户端，因此系统不允许这个版本打开网络连接。

本网站

本网站是静态页面，没有分析统计。切换语言只会打开本站的另一个页面。release.json 只在构建网站时用来找到当前的下载文件，应用从来不会请求它。除简体中文外，其他语言的页面显示这份英文政策。

联系

问题和请求请提交到 GitHub issues。
